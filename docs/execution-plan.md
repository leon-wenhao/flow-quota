## 稳定接口

UI 通过 NSXPCConnection 与每用户 Agent 通信，消息仅包含 Codable 元数据。客户端和服务端都验证对端代码身份；错误与超时明确返回。
Agent 统一管理 SQLite，过滤扩展不得执行同步数据库写入。最终扩展通信要先验证其沙箱和签名环境，不假设可任意访问 LaunchAgent 或共享目录。

共享规则与测试向量集中维护；当日额度按应用聚合，与连接和 PID 无关。预算先持久化再发放，未结算部分保守保留。
