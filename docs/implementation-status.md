# 实际进度与验证记录

日期：2026-11-04。本轮仅 macOS；正式发行、签名公证与 Windows 工程不在当前交付范围。

当前是阶段性交付，完整 V1 尚未完成；主要阻塞为真实网络过滤系统扩展的部署与验收。

## 已实现的独立模块

- 原生 SwiftUI 菜单栏与可复用面板、额度编辑、设置、首次说明；空数据和未就绪均如实显示。
- 精确十进制字节换算、Gregorian 本地日期、纯额度判定、提醒去重提议、actor 原子预算。
- SQLite 实体关系、约束、索引、v1→v2 事务迁移、规则版本、实际用量、通知去重、先持久化再发放的租约。
- Agent 单写入存储与日期清理、XPC 双向代码身份校验、消息大小限制、超时与取消、错误返回。
- 网络成本信号和当前会话路径标记；网络更新后取消手动标记，不把接口名称当持久热点身份。
- 登录项状态与操作、本地通知真实授权状态及显式请求入口；实际系统批准未自动操作。
- 不含扩展的开发服务显式修复入口；本地数据目录所有者与权限检查、拒绝符号链接。
- arm64 与 x86_64 编译、开发 .app 打包脚本；Windows 预留入口与平台无关测试向量。

## 阻塞：真实网络保护

当前没有打包或安装 Flow Quota 网络过滤扩展，不能提供真实按应用流量、系统后台进程归因、热点限额或超额阻断。服务对规则保存返回“无法确认生效”，UI 不展示保护成功。

本机前置检查：Xcode 27.2 可用，`security find-identity -v -p codesigning` 返回 0 valid identities，`csrutil status` 显示 SIP enabled，`systemextensionsctl list` 显示 0 extension(s)。未修改全局安全配置，也未申请证书。

Apple 系统扩展部署文档要求激活时验证代码身份及 entitlement。当前尚未具备并验证可行的官方开发部署路径；应用能够启动不作为满足该条件的证据。相关任务暂停，下一步先核实并满足激活条件，再进行最小真实计量／阻断样机。不得用其他网络架构、轮询流量或假数据替代。

## 复查修正

- 现有数据目录与文件不能仅依赖创建属性和 umask；增加所有者、类型、权限、符号链接与硬链接检查。
- 开发包重建后，旧 Agent 的 cdhash 需求可能过期；提供显式修复，不放松身份校验。
- Swift 与 SQLite 对 Unicode 身份的相等口径不同；账本边界统一要求 NFC，旧库异常明确报错，禁止静默合并或丢弃用量。
- 通知种类复用 Core 定义，存储保留旧 SQL 值映射；关键状态与转换测试纳入正式测试 target。
