# 完整流量与 Clash 来源拆分方案

2026-11-06，用户批准实施。取代“内核与辅助来源分列＋常驻归因核对”的主界面。

## 用户看到什么

- Mac 今日／时段总量继续使用单一物理接口计数，识别失败不减量。
- Clash 父项 800 MB，在来源可用时展示虎牙（Clash）300 MB、YouTube（Clash）300 MB、其他未识别（Clash）200 MB。父项仅是分组总量，不再与子项重复加入排名、图例或通知明细。
- 主列表、菜单栏前三项、图表时段明细与悬停共用拆分器；预警保留触发时拆分结果，旧事件不回填。
- 日常界面只显示总量、上传／下载、来源名称与用量。常驻核对长文及辅助来源列表移除；原进程比例饼图改为与表格完全相同的已拆分来源上传／下载分布；原始计数、API 状态与限制在计量详情可查。采样、持久化、容量及查询错误仍直接可见。

## 数据与边界

代理父项为精确身份匹配的 nettop 内核；来源为 Mihomo 连续连接增量。它们不是逐字节同一计量器，不能声称还原每个网络包的真实用途。拆分是以父项为上限的来源展示：只接受相同日期、网络类别和时间桶内的已识别来源，上传和下载分别检查。已识别来源两方向均不超过父项时，保留原数，剩余量归“其他未识别（Clash）”；未识别连接、未捕获连接、旧数据、协议／时间差均在剩余量内，不能当成一个可配置额度的真实应用。

任一方向来源超出父项、数字无效或身份冲突时，该桶全部父项归入未识别，保留原始证据到诊断，不裁剪、缩放或借别的时段补足；无父项时不能从来源反造父项。每日列表必须与当天分钟分桶的结果相加一致，避免全天相减掩盖某分钟超额。全机普通应用也先经过同一接口分钟父项核对；冲突分钟归入接口未识别，原始 nettop 数值仍在计量详情保留。主图继续显示同一物理接口量。

## schema v9（先设计后实现）

新实体 `clash_source_usage_minutes`：保存已验证的当天 Clash 来源分钟汇总，使暂停、服务重启不删除已记录明细。字段：day TEXT（本地自然日）、category TEXT（metered/ordinary）、minute_start_ms INTEGER（UTC 毫秒，分钟对齐）、source_id TEXT（既有受控站点／应用身份，最多 8192 UTF-8 bytes）、name TEXT（显示名，最多 512 bytes）、identified INTEGER（0/1）、uploaded_bytes / downloaded_bytes INTEGER（非负、合计不溢出 Int64）、sample_count INTEGER（正数）。主键 `(day, category, minute_start_ms, source_id)` 支持分类与范围读取，不增加重复索引；无外键，因为来源不是应用额度身份。只存聚合，不保存原始域名、IP、连接 ID、内容或规则。

每类当日最多 128 个来源、32768 个来源分钟行，超过时事务失败、提示可见；父项与接口独立继续计量，未保存部分体现为未识别。约两秒每批事务写入；原计数基线仅在提交成功后推进，失败重建来源基线，不补间断。服务读取旧内存累计不回填到新表，升级前父项量保留为未识别。所有读取与写入由服务经 Store actor 负责，UI 不直接访问 SQLite。

迁移 8→9 在事务内建表、更新 user_version，失败回滚，不重建数据库。跨日及日期回退与既有当天清理事务统一删除，保留 secure_delete、WAL 截断与失败重试。分钟来源合并查询及每日派生结果不另建日表，不持久化派生“其他未识别”。

## 验证

仅用合成计数、临时数据库、原生视图及编译检查。覆盖 800=300+300+200、无 API 全量未识别、上下行独立、超额回退、同名不同身份、分钟／类别隔离、重启读取、跨日删除、迁移回滚、容量及写入故障、主图总量与预警不受识别影响。不得为验收生成下载、上传或热点实验流量。

官方依据：项目锁定 Swift tools 6.0、最低 macOS 14、Sparkle 2.10.1；沿用 Mihomo v1.19.33 connections 元数据与连续增量解析。SQLite 官方 [CREATE TABLE / CHECK](https://www.sqlite.org/lang_createtable.html) 与 [事务](https://www.sqlite.org/lang_transaction.html) 已核对：显式 NOT NULL、整数/范围约束及复合主键；DDL、写入与版本更新沿用同一事务。临时库迁移冲突/故障注入已验证回滚，实际链接 SQLite 3.54.0。没有新增系统权限或网络采集 API；未实测 VPN、运营商账单或原始应用精确还原。
